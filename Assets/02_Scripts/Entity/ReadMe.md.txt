몬스터와 플레이어 모두 살아있는 개체이므로,
이동/공격/애니메이션 등등 을 각각 모듈로 만들어서 붙여준다.

이동의 경우, ISetMoveDirection 인터페이스를 만들고, 몬스터와 플레이어 각각 이동 방향을 정하는 코드를 따로 구현하여 붙여주고, 
이동 모듈에서는 해당 방향으로 이동하기만 한다.

/*
몬스터는 생성될 때마다 Player를 태그로 찾는 것이 최적화에 좋지 않을거라 생각하여 현재는 static transform Player_t를 넣어놨다. 하지만 추후 오브젝트 풀 을 구현하면 리팩토링해도될듯

몬스터의 경우, 현재는 가까이 가기만 하면 데미지가 들어가도록 구현할 것이기 때문에 몬스터마다 공격 모듈을 구현해줄 필요는 없을듯. 나중에 오브젝트 풀을 구현해주면 몬스터 애니메이션만 바꿔주고, 필요하면 scale만 조정하는 방식으로

현재는 몬스터의 SetMoveDirection 컴포넌트를 몬스터 오브젝트에 넣어주고, 직접 불러오고 있음. 하지만 나중에 스포너를 구현하면 스포너에서 SetMoveDirection을 지정해주도록 한다.
*/
